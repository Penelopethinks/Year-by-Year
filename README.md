# Year by Year

A clean, customizable calendar storefront for Year by Year.

## Features
- Customer calendar browsing and cart
- Checkout/order form
- Admin dashboard protected by code 713
- Calendar/product management
- Site settings and store controls
- No wallpaper/theme system
- Browser-based PDF/image preview with PDF.js

> This version is a front-end prototype. Orders and uploaded files are stored in the browser, so a shared production database/payment system should be added before accepting real orders.
